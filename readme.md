Function:

This addon will automate the purchasing of Conquest Items from NPCs. This uses key press commands and DOES NOT read or inject packets.

Limitations:

DO NOT USE the FastCS addon while using this addon. The game engine runs uncapped and causes key press sends to not work properly.

This addon is set up to ONLY purchase the following items:

Windurst - Mercenary Captain's Scythe (Rank 3)
Sandoria - Royal Squire's Halberd (Rank 3)
Bastok - Musketeer Gun (Rank 5)

The Musketeer Gun is only available when Bastok is ranked 1st in Conquest


Depending on potential lag and connectivity issues you may need to adjust the timing options in conquest.lua manually.


Usage:

Stand near a conquest NPC in any of the main nations or the gates in Jueno. The addon uses a simple /targetnpc command and will select the closest NPC.

Use the following command to begin the process.

//conquest start <Nation> #

For example if you wished to purchase 10 Musketeer Guns:

//conquest start Bastok 10
